# Departments

Habit Tracker is run by the departments of Ritvi Apps. Each department's process, rules and skills live once, in the org's handbook (`.handbook/departments/`). This folder holds only what is true for Habit Tracker: its own notes, rules, skills and schedules, one folder per department, read on top of the org's.
