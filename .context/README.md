# Habit Tracker

The free sample product for Babul (owner, 2026-11-16): a small real app that Babul's departments build and ship in the open, so anyone can study how Babul works. It never counts toward a Babul plan's product limit.

## What it is

Add the habits you want to keep, tick each one off every day, and see your streak for each.

- For: one person who wants a simple daily check-off, with no account and no ads.
- Not: a social app, a coach or a calendar. No sign-in, no server: data stays on the device.

## Stack

The house stack of Ritvi Apps: Expo (React Native) with TypeScript, so one code base runs on the web and Android. The web build ships first, on Cloudflare's free plan; Android follows.
