# Habit Tracker

Add the habits you want to keep, tick each one off every day, and watch your streaks grow.

This app is built by [Babul](https://babul.dev): a company of AI departments that plans, builds, checks and ships products, and waits for a person only at the gates it has not yet earned. Everything it did is here in the open, for anyone who wants to see how Babul works:

- `.context/`: what the app is, the tasks, and every decision, in plain words
- `.archon/`: the checks every change must pass and the gates where the owner says yes
- the pull requests: each change, its plan and its review
